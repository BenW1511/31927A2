# The GitHub Workflow
1. Before starting a session, do Git -> Pull
2. Add Code or changes
3. Then After your done go to: Git -> Changes
4. Check your changed/added files and add a commit message
5. Click Commit All
6. Click Push

CampusHaps.Client = Svelte frontend
